# 订单取消：示例规格

以下规则由本教学样例的需求方确认，仅适用于该样例。

| 规则 | 已确认行为 | 场景 |
| --- | --- | --- |
| R1 | 所有者可取消未发货订单，成功后状态为 `cancelled` | S1：alice 取消自己的 `unshipped` 订单；S2：换一位所有者和不同订单仍成立 |
| R2 | 非所有者取消时拒绝，订单保持不变 | S3：bob 取消 alice 的订单 |
| R3 | 已发货订单取消时拒绝，订单保持不变 | S4：alice 取消自己的 `shipped` 订单 |

示例接口为 `cancel_order(order, actor_id) -> bool`，成功返回 `True`，拒绝返回 `False`。`Order` 有 `order_id`、`owner_id` 和 `status` 三个字段；只使用内存对象，不包含数据库或外部服务。

退款、库存回补、重复取消、订单不存在以及并发处理均未约定。这些问题不阻塞 S1–S4，也不在本例实现或验收范围内。最终检查只能证明内存中的决策与状态变更，不能证明线上权限接线、持久化或事务。
