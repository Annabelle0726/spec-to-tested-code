## 可运行示例

编写教学示例时，先在不完整实现上实际运行四个测试，观察到四项断言失败，再实现所有者／状态判断和取消状态变更，四项通过。

```sh
python -B -m unittest discover -s examples/order-cancellation -p test_order.py -v
python -B examples/order-cancellation/demo.py
```

```text
red:   tests=4, failures=4, errors=0, skipped=0, exit_code=1
green: tests=4, failures=0, errors=0, skipped=0, exit_code=0
RED -> GREEN verified
```
